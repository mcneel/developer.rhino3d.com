{{- /* segmented.html — two-way segmented control (the homepage's "New License / Upgrade" switch). Two modes: Panes: shows the element matching the selected segment and hides the other. {{< segmented A="New License" Atarget="#pricing-new" B="Upgrade" Btarget="#pricing-upgrade" >}} Links: each segment is a link to a page and the segment for the current page is drawn selected. The Learn Rhino / Teach Rhino pages use it as a cross-page toggle (WWW-3604). Real anchors, so it works without the script. {{< segmented A="Learn Rhino" Alink="/learn2/" B="Teach Rhino" Blink="/teach2/" >}} Params: A, B — segment labels (default "A" / "B") Atarget, Btarget — CSS selectors of the two panes, e.g. "#pricing-new"; give the B pane style="display: none;" so it stays hidden until the script runs Alink, Blink — URLs: the segment is a link. The selected segment is plain text (it is the current page). A site-root page path ("/teach2/") resolves to the page in the current language. selected — "A" or "B": the segment drawn selected on load. Default: the segment whose link is the current page, else A. Bquery — query string that pre-selects B on page load, e.g. Bquery="upgrade=1" makes /?upgrade=1 open the B pane (e-news mailings link to /?upgrade=1#price). "key" alone matches on presence, "key=value" on an exact value. Panes only. id — id stem for this control's radios, e.g. id="platform". Default: segmented-. Only needed if you want stable ids. Any number of controls per page (WWW-3776). Each gets its own radio ids and its own radio group name from `id`, and hands the pane selectors to the script in data attributes rather than having them templated into an inline script — so two controls neither collide on ids nor share a radio group. Style: assets/scss/_shortcodes/_segmented.scss. Script: assets/script/segmented.js, loaded once by partials/js-scripts.html when the "has_segmented" flag below is set — i.e. only when a control has panes to switch. (Like the other js-scripts-loaded shortcodes, the script is not emitted on a page_options.plain page, which does not include js-scripts.) */ -}} {{- $A := .Get "A" | default "A" -}} {{- $B := .Get "B" | default "B" -}} {{- $Atarget := .Get "Atarget" | default "" -}} {{- $Btarget := .Get "Btarget" | default "" -}} {{- $Alink := .Get "Alink" | default "" -}} {{- $Blink := .Get "Blink" | default "" -}} {{- /* Pages live under a language prefix (defaultContentLanguageInSubdir): /teach2/ is really /en/teach2/. Site-root page paths resolve to the page in the current language, like markdown links do (partials/resolve-link), so the toggle works on hugo server too, where no proxy adds the prefix. */ -}} {{- $Alink = partial "resolve-link.html" (dict "page" .Page "url" $Alink) -}} {{- $Blink = partial "resolve-link.html" (dict "page" .Page "url" $Blink) -}} {{- $Bquery := .Get "Bquery" | default "" -}} {{- $selected := .Get "selected" | default "" -}} {{- /* Unique per control: the radio ids and the radio group name. Ordinal is the shortcode's position in the page, so two controls never collide. */ -}} {{- $id := .Get "id" | default (printf "segmented-%d" .Ordinal) -}} {{- if not (in (slice "" "A" "B") $selected) -}} Error: segmented: selected must be A or B. {{- else -}} {{- /* Resolved links equal RelPermalink; the suffix match covers a link that did not resolve to a page. */ -}} {{- if eq $selected "" -}} {{- $here := .Page.RelPermalink -}} {{- if and (ne $Blink "") (or (eq $Blink $here) (hasSuffix $here $Blink)) }}{{ $selected = "B" }}{{ else }}{{ $selected = "A" }}{{ end -}} {{- end -}} {{- $links := or (ne $Alink "") (ne $Blink "") -}} {{- $panes := or (ne $Atarget "") (ne $Btarget "") -}} {{- /* Tells partials/js-scripts.html to load segmented.js once for this page. */ -}} {{- if $panes }}{{ .Page.Store.Set "has_segmented" true }}{{ end -}}
{{- end -}}
